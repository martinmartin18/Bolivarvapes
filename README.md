## 🚀 Cómo usar

1. Reemplaza las imágenes en la carpeta `/images/` con tus propias fotos de productos
2. Personaliza los precios y descripciones según tu inventario
3. El número de WhatsApp se puede cambiar en el archivo `index.html`

## 📝 Para editar

- Edita `index.html` para cambiar productos, precios y descripciones
- Edita `css/styles.css` para cambiar los colores y estilos
- Actualiza las imágenes en la carpeta `/images/`
